# Plan: v0.1 (issues #3, #4, #5)

This plan carries out [`architecture.md`](../architecture.md), using the sources chosen in [`inventory.md`](../inventory.md) and the regression IDs from [`regressions.md`](../regressions.md). Each step is one pull request with tests, reviewed by Codex `gpt-6-astra` and by the coordinating session before it merges.

## Conventions for every step

- **Toolchain:** `uv` with Python ≥ 3.12. `make check` runs lint and unit tests and is the definition of green; CI runs it on every push and pull request.
- **Regression tests:** each regression ID a step covers gets at least one test, and the test's docstring starts with the ID (for example `"""B01: ..."""`), so `grep -r '"""B01'` finds them.
- **Provenance:** every module under `src/` starts with a provenance header. Code from an earlier study enters through `expcore.provenance.sanitise import`: one commit holds the sanitised source with its header, and later commits change it. A module written fresh says `# Provenance: new`.
- **Study tokens:** the study-token check runs over every tracked file in `make check`, and over every commit of a push or pull request in CI.
- **Coding:** Sonnet subagents write the code; the orchestrating session reviews every diff before review requests go out.
